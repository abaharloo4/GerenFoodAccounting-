# Roadmap - سیستم حسابداری و تطبیق صندوق کافه

## فاز ۰ — راه‌اندازی اولیه پروژه
- [x] راه‌اندازی پروژه‌ی Electron + Vite + React + TypeScript
- [x] پیکربندی electron-builder برای build ویندوز
- [x] اتصال SQLite (sql.js / WASM) و اجرای schema اولیه
- [x] پیاده‌سازی ساختار IPC پایه (contextBridge + preload)
- [x] راه‌اندازی فونت فارسی و RTL layout پایه

## فاز ۱ — احراز هویت و مدیریت کاربر
- [x] جدول و منطق `users`
- [x] صفحه‌ی ورود (شماره تماس + رمز عبور)
- [x] هش کردن رمز عبور با bcrypt
- [x] Session ساده در main process + محافظت از route ها بر اساس نقش
- [x] پنل مدیر برای افزودن/غیرفعال‌سازی حسابدار

## فاز ۲ — ثبت شیفت و ورودی‌های اصلی
- [x] فرم شروع شیفت (انتخاب تاریخ شمسی خودکار + نوع شیفت صبح/عصر)
- [x] فیلد فروش سیستم
- [x] فیلد نقد
- [x] لیست چندتایی پوزها (فروش کارتخوان)
- [x] لیست چندتایی اعتباری (توضیحات + مبلغ)
- [x] لیست چندتایی کسری شناخته‌شده
- [x] لیست چندتایی اضاف شناخته‌شده
- [x] امکان ویرایش چندباره در طول شیفت

## فاز ۳ — موتور محاسباتی و نمایش نتیجه
- [x] پیاده‌سازی `calculation.service.ts` طبق فرمول PRD
- [x] تست واحد با مثال عددی تأییدشده
- [x] نمایش زنده‌ی نتایج در فرم (جمع اعتباری، جمع کسری، جمع اضاف، باقی‌مانده‌ی ناشناخته)
- [x] رنگ‌بندی بصری برای کسری (قرمز) / اضاف (سبز) / متعادل (خنثی)

## فاز ۴ — پنل مدیر و گزارش‌گیری
- [x] داشبورد مدیر: مشاهده‌ی همه‌ی شیفت‌ها با فیلتر تاریخ/حسابدار/نوع شیفت
- [x] امکان قفل کردن (lock) شیفت توسط مدیر
- [x] نمودار و آمار روند کسری/اضاف در طول زمان
- [x] Export گزارش (Excel/CSV) برای بازه‌ی زمانی دلخواه

## فاز ۵ — تاریخچه، Audit Log و پشتیبان‌گیری
- [x] پیاده‌سازی کامل `audit_log` روی تمام عملیات create/update
- [x] صفحه‌ی مشاهده‌ی تاریخچه‌ی تغییرات یک شیفت خاص (برای مدیر)
- [x] پشتیبان‌گیری خودکار دوره‌ای از فایل SQLite
- [x] دکمه‌ی پشتیبان‌گیری دستی

## فاز ۶ — پرداخت (Polish) و بسته‌بندی نهایی
- [x] تست کامل UX روی صفحه‌نمایش‌های مختلف
- [x] بسته‌بندی نهایی با electron-builder (نصب‌کننده‌ی ویندوز)
- [x] آماده‌سازی electron-updater (معماری آماده به کار)
- [x] مستندسازی نهایی راهنمای استفاده برای حسابدار و مدیر

## فاز ۷ — سیستم انتشار و آپدیت خودکار گیت‌هاب (نسخه ۱.۰.۶)
- [x] اتصال سیستم بررسی نسخه به GitHub Releases API
- [x] دانلود بسته نصاب با پیشرفت‌بار زنده (درصد، سرعت، حجم انتقالی، مراحل)
- [x] جایگزینی امن فایل با نابودی صریح پنجره‌ها و آزادسازی فایل اجرایی (`app.exit(0)`)
- [x] نوسازی خودکار آیکون ویندوز و حذف شورتکات‌های قدیمی از طریق NSIS
- [x] یکپارچه‌سازی و داینامیک‌سازی نسخه در تمامی فوترها، گزارش‌های Excel و PDF

## آینده (خارج از فازهای فعلی)
- پشتیبانی چندشعبه‌ای / چند کافه (نیازمند بازطراحی جزئی schema و لایه‌ی auth)
- نسخه‌ی شبکه‌ای/چندکامپیوتری یا انتقال به MySQL/backend وب‌محور
- اتصال مستقیم به دستگاه‌های پوز برای دریافت خودکار فروش کارتخوان
- اعلان خودکار هنگام عبور کسری/اضاف از یک آستانه‌ی مشخص
